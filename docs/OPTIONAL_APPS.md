# Installed apps versus bundled features

Quiet TV discovers installed apps that advertise an Android TV launch activity. The README screenshots show the test TV’s installed collection; these applications are not redistributed with Quiet TV.

- **AirScreen:** an independently installed receiver app. Quiet TV does not itself implement AirPlay, Chromecast or DRM video reception.
- **YouTube, YouTube Music, Netflix and other players:** launched through their normal Android activities. Availability, accounts, subscriptions, background playback and cast behavior belong to those apps.
- **OxygenPlay, Live TV, Camera, Weather and OnePlus utilities:** firmware applications. Quiet TV may provide a simplified tile illustration while preserving the original launch target.
- **Connect device and MK-IV Screensaver:** bundled Quiet TV features.

HDMI device names come from the TV input framework. App icons/brands shown in screenshots are not an endorsement or affiliation. Optional package cleanup is separate from app discovery; see [DEBLOAT.md](DEBLOAT.md).
